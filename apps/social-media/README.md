# 自媒体工作台

璀璨星图「应用合集」中的独立应用，统一管理自媒体信息与内容工作流。

## 当前版本

基础应用骨架：已提供合集入口、独立页面、平台范围与开发阶段说明。尚未接入账号、数据收集、内容存储或真实发布。

- 入口：应用合集 → 自媒体工作台，或前端地址 `/#social-media`。
- 页面源码：`frontend/src/components/apps/socialMedia/SocialMediaView.tsx`。
- 本目录：存放本应用后续服务、平台适配与说明；当前复用主项目 React 前端，无需单独安装或启动。

## 平台范围

首批规划小红书、X（推特）、微信公众号；后续按需扩展其他平台。

## 逐步开发方向

1. 信息收集：先支持手动录入链接、内容和来源，再逐步增加平台采集能力。
2. 信息筛选：标签、搜索、去重、保留与忽略。
3. 内容处理：摘要、笔记、选题和草稿编辑。
4. 发布管理：先提供发布清单与人工发布记录，再按各平台实际能力接入发布。

每一步单独明确需求并实现；上述功能为开发方向，不代表已具备对应能力。
