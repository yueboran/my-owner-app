## 执行队列

网址抓取通过“加入执行队列”创建任务。引擎逐个执行，当前任务运行时可以继续添加任务，无需先暂停。

右侧工作区采用“执行与校验”统一卡片，以 Tab 标签（“执行队列”与“抓取校验”）进行视图切换，保持左右两栏对称布局。队列面板支持查看当前任务、查看等待任务、上移、下移、移至队首、移出队列以及暂停/运行队列；点击“查看”或队列完成后可无缝切换到“抓取校验”查看进度与导出成果。移出只取消排队，任务和已保存章节仍在历史记录中，可继续任务再次加入队列。

- 暂停队列只阻止调度下一个任务，当前任务继续完成。
- 暂停当前任务会同时暂停队列，并保留断点任务在队首。
- 任务失败时暂停队列，错误保留在任务详情；处理后可以继续该任务，也可运行其余队列任务。
- 队列保存在数据目录的 `queue.json`。服务重启恢复等待顺序和未完成的队列任务，需要手动点击“运行队列”，不会自动重复启动抓取。
- 新队列接入可以复用旧接入服务的活动引擎和浏览器，无需为了启用队列中断已有抓取。

测试：`node --test integration/*.test.cjs`，含并发提交、排序移出、失败暂停、重启恢复、热接入保持当前任务以及真实浏览器顺序采集。

## 笔趣阁

“网址抓取”右侧新增“笔趣阁”标签。粘贴作品或章节链接（如 `https://www.bqg308.xyz/#/book/30132/5.html`），读取目录后核对书名及起止章节，再加入原有执行队列。章节链接自动将范围起点设为该章；每次最多 2000 章，目录读取不会自动开始抓取。

`integration/bqg.cjs` 从 `ebook-ai-studio/server/bqg_import.py` 迁移 JSON API 适配：章节 token、Origin/Referer 跟随输入域名、已知诱饵正文识别、全局串行且间隔至少 5 秒的纠错请求、最多 4 次重试和 8 章并发。仅请求作品信息、目录、正文及纠错 JSON 接口，不获取源站 HTML、不打开阅读浏览器。段落转义为 EPUB 所需的安全标记，继续使用原电子书导出器生成 EPUB、TXT 和离线阅读文件。

默认支持 `bqg308.xyz`、`bqg726.xyz`（含 www）。同协议镜像可通过 `BQG_EXTRA_HOSTS` 配置逗号分隔的完整域名（不含协议及路径），重启服务后生效。不会将任意相似域名自动视为同站点，也不自动跟随接口重定向；新域名仍须兼容现有 API 与 token 算法。

笔趣阁任务与网址任务共享队列、暂停/继续、历史、编辑及下载；暂停等待正在请求的章节落盘，再保留断点，继续时跳过完整章节。可编辑同书镜像地址以恢复旧域名失效的任务。队列仍串行执行整本任务，单个笔趣阁任务最多 8 章并发。

验证：`node --test integration/bqg.test.cjs integration/bqg-ui.test.cjs`。浏览器验收使用隔离临时目录与接口夹具，不写入用户历史记录。原版 lib/public/server.cjs 未修改，新增功能仅在项目接入层生效。

## 会话 Cookie 持久化修复

固定浏览器用户目录不能保证会话型 Cookie 在 Chromium 退出后保留。integration/session.cjs 在本机浏览器会话目录保存 qq-session.json（含登录凭证，不随源码提交），每秒同步 QQ 域 Cookie；确认登录时同步保存，程序调用关闭时先保存。再次建立浏览器上下文时，仅补回缺失且未过期的 Cookie，保留原始有效期，不覆盖已有凭证。主动退出产生的 Cookie 清除会同步保存。既有 localStorage 继续由浏览器固定用户目录保存。网站服务端失效或风控验证仍可能要求重新登录。

热升级复用当前上下文并开始保存，不关闭用户窗口；升级前已丢失的会话不能恢复，需要重新登录一次。验证：node --test integration/session.test.cjs，使用隔离临时目录和测试Cookie，覆盖原生Browser.close、程序实例重建、会话Cookie恢复与退出登录不复活。

详情页等待采用60秒总时限，同时识别本次搜索原页及新增标签页；目标网址匹配且已有页面文字即继续，不等待可能被第三方脚本拖延的DOMContentLoaded。超过时限提示检查网络、登录或验证；不自动重复点击。测试覆盖延迟新页、阻塞脚本、同页跳转与错误目标超时。

搜索成功或失败结束后，自动关闭本次独立搜索页及其弹出的结果页、详情页。执行前已有页面与无关手动页面保留；关闭前同步登录会话，不清理登录数据。返回的书名与阅读网址照常回填工作台。
