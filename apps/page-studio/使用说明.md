# 书页工坊 1.5

完整解压，双击启动.cmd，打开 http://127.0.0.1:43821。

## 文字＋图片导出（网址抓取默认）

1. 输入 QQ 阅读的阅读页、详情页或目录页网址，打开阅读浏览器。
2. 在独立浏览器中完成登录、订阅或验证。
3. 核对起始章 a 和结束章 b，开始抓取，范围包含 a、b。
4. 下载 EPUB、离线 HTML；有正文时同时提供 TXT。

文字版保存恢复后的真实文字，能搜索、复制、调整字号；标题、段落、表格、加粗和独立插图按阅读顺序保留。没有把正文截图，也不使用 OCR。图片嵌入文件，离线不需要原网站签名地址。无法验证的字体映射会停止并明确报错，不会自动退回截图或猜测汉字。此版本已经用教材的封面、版权、前言和正文验证；不能承诺任意网站、任意字体均已适配。

QQ 阅读自动识别书号；其他网站使用 https://example.com/book/{n}.html 模板，可指定正文 CSS 选择器。随机章节 ID、整页画布或无法识别的结构需要单独适配。

## 旧截图任务

旧任务保留，不会通过重新导出自动变成文字。选中旧任务后点击“重新抓取文字＋图片版”，程序创建新任务并重新读取网页；原任务、已下载文件保留。新文字任务的“继续任务”会跳过已完整保存的文字章节。

导入 HTML 仍是旧版图片转换功能，不会把截图识别为准确文字。请优先从原阅读网址建立文字任务。

## 数据与错误

数据只保存在本机 数据/任务/，登录配置保存在 数据/浏览器会话/。完整章节自动保存，中断可继续。图片获取失败会自动重试3次。对外错误提示隐藏底层请求日志和资源网址，避免显示Cookie及签名参数。旧截图任务的历史错误在界面也会脱敏。

正文仍逐块滚动，确认屏幕外变形已恢复，且保存前后没有变化。这能防止导出过程带入已知变形字符，不能代替对原网站文字逐字校对。

运行需要已安装的 Chrome 或 Edge；Node.js 与 Playwright Core 已随包提供。解压整个文件夹后运行，不要只复制启动.cmd。关闭启动窗口会停止服务。发布包不包含个人浏览器会话或抓取任务。

## 1.4 提速

文字按恢复状态与连续稳定性决定何时保存，替代每段固定180ms等待；不减少恢复重试时间窗。正文图片最多3路预取，与文字串行校验重叠执行，仍按原顺序嵌入，下载失败重试或停止。批量筛选正文块，文字任务去除每章固定500ms空等。没有增加章节并发，没有取消字体、内容恢复、完整图片或保存前后的一致性检查。

本机固定测试80段变形正文加6张图片：17933ms→6744ms，约2.66倍；文字、结构、图片SHA256相同。真实网页提速随网络和排版变化，不能保证固定倍数。


## 编辑任务记录

任务记录右侧点击‘编辑’，修改名称、来源网址与章节范围；保存后重新生成已有章节的下载文件。运行期间先暂停再编辑。已有正文的记录只允许同一来源，范围必须包含已保存章节；扩大范围后可继续抓取缺少的章节。导入任务只改名称。取消或验证失败不会改动记录。旧下载文件保留。
