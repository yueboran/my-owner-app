# 招聘浏览器代理

璀璨星图「应用合集」中的独立应用，计划调用 Laya 与 LLM，对 BOSS直聘等招聘网站执行浏览器代理任务。

## 当前版本

仅建立应用入口与基础页面，尚未接入 Laya、LLM、浏览器会话或招聘网站，不会执行搜索、沟通或投递。

- 入口：应用合集 → 招聘浏览器代理，或前端地址 `/#recruitment-agent`。
- 页面：`frontend/src/components/apps/recruitmentAgent/RecruitmentAgentView.tsx`。
- 本目录用于后续代理服务、网站适配及配置说明；当前复用主项目 React 前端，无需单独安装或启动。

## 逐步开发方向

1. 基础连接：明确用户所指 Laya 的项目、版本和调用方式，接入浏览器会话与 LLM 配置，并验证连接。
2. 页面观察：识别当前招聘页面，读取职位、公司及岗位要求。
3. 任务执行：将自然语言需求转为可查看的操作步骤，逐步支持职位搜索、条件筛选与详情整理。
4. 求职跟进：按后续明确的需求加入收藏、沟通、投递和进度管理。

## 待明确

- 首个需要实现的招聘场景及浏览器连接方式。

上述内容为开发方向，各能力将在后续单独实现。
