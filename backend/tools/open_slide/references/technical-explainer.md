# 技术图解 · Visual Explainer 适配

来源：Visual Explainer 0.12.0 的 figure-first、mechanism、SVG、data 与 small-multiples 规则。画布与交互按 Open Slide 重写，不移植长网页目录和视口单位。

## 选图

流程：步骤、决策与回路；每条边标动作或条件。架构：服务、存储与边界；节点用形状区分，虚线边界标含义，异步边用虚线。时序：参与者列、时间向下，每条消息一行。状态：转移标触发条件。数据：比较用零起点条形、趋势用折线、占比用堆叠/waffle。技术比较：同尺度同坐标 small multiples，把增加/移除的关系真正画出来。

每页标题是结论，首屏图示支撑结论。图用 figure + figcaption，SVG role=img 和 aria-label；正文是图的注释，不是重复图的长段落。概念图可简单，但不能仅把名称装进几个方框。

## 固定画布图纸

图纸宽1680，高560–640，位于120px安全区；SVG viewBox 接近实际显示宽。节点160–260px宽，间距≥80px；图标签28–32px，页正文36–40px。使用直角连线和共享箭头；边先画、节点后画。绘图文字必须在框内；不要把大图整体缩到标签无法投屏阅读。

所有主题关键色和字体消费 --osd-*，额外底纹低对比。存储用圆柱、服务用矩形、可选/停用用虚线；不能仅靠红绿区别状态。标注优先直接写在节点/边上，而非远处图例。模板编号只给真正的顺序。

## 数据诚实

有数据时记录来源、时间、单位、样本/分母和缺失值；没有数据先用占位或明确标注的教学模拟值。不能把模型数值写成实测结论。零起点条形、同尺度比较；显示直接值标签。模型控件必须写公式及假设，调用同一个纯函数更新数字和图。

## 交互与交付

机制展示可用原生 Steps（读其 reference 后使用）或少量原生按钮/slider。默认展示完整结论，不自动播放。状态同时写文字、形状与位置。

原生 HTML 导出会把 React 页面变成静态 DOM，React 事件不会自动保留。此次缓存示例用 data-cache-figure/data-cache-choice/data-cache-route DOM 契约，pack_html.py 在单文件中恢复场景按钮。新控件必须另加可测试的导出适配，或把离线页明确交付为静态快照；不能保留假按钮。

验证：预览 ready、SVG文字边界、连线路径、值标签、对比度、keyboard/reduced motion、原生交互；导出后断网重新打开，逐页翻页并重新验证交互。asset中的kit只是起点，复杂图按需求重构；不引入CDN或图形依赖。
